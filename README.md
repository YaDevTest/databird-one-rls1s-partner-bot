DataBird One — RLS1S Partner Bot

Official partner program bot for DataBird One RLS Driver.

This repository contains the source code of the Telegram bot used for the partner program of DataBird One RLS Driver — a 1C driver for Rongta RLS1000/RLS1100 label scales.

🌐 Product: https://databird.one/rls1s/
🌐 DataBird One: https://databird.one/

---

About DataBird One

DataBird One develops software for business automation and integration with retail equipment.

RLS Driver

DataBird One RLS Driver provides integration between 1C and Rongta RLS1000/RLS1100 label scales.

The driver supports product, price and barcode export from 1C directly to the scales.

More information:

https://databird.one/rls1s/

---

Partner Bot

The Telegram bot is used to manage the DataBird One partner program.

It provides partner-related functionality such as:

- partner registration;
- referral links;
- referral tracking;
- partner statistics;
- partner notifications.

Security

Never commit:

- Telegram bot tokens;
- API keys;
- database credentials;
- production configuration;
- private keys;
- personal or customer data.

Use environment variables and ".env.example" for local configuration.
